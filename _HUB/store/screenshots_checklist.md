# Screenshots Checklist — The WakeApp (App Store Connect)

> iPhone only. **No iPad, no Apple Watch** → no iPad/Watch screenshots required.
> Every screen should reinforce the two pillars: **personalization** (make it yours) + **simplicity** (clean, easy to run).
> No "AI"/"IA" anywhere in captions or mockups.

---

## 1. Required sizes (iPhone)

App Store Connect requires screenshots for the two largest iPhone display classes. If you upload the 6.9" set, Apple can scale it for smaller devices, but providing both 6.9" and 6.5" is the safe, brief-mandated approach.

| Display class | Devices | Required resolution (portrait) | Required? |
|---|---|---|---|
| **6.9"** | iPhone 16 Pro Max / 15 Pro Max-class | **1320 × 2868 px** | ✅ Yes |
| **6.5"** | iPhone 11 Pro Max / XS Max-class | **1242 × 2688 px** | ✅ Yes |

- Format: PNG or JPEG, RGB, no transparency, no rounded corners/device frame baked in (unless intentional marketing frame).
- Count: minimum **1**, maximum **10** per size. **Recommended: 5–6.**
- Localize: provide both **EN-US** and **FR** sets (captions translated).
- Orientation: **portrait** (the app is phone-portrait).

## 2. Screens to capture (ordered — first 2-3 matter most)

| # | Screen | What it shows | Pillar | Suggested caption EN / FR |
|---|---|---|---|---|
| 1 | **Home / Control Center** | The personalized dashboard — sessions, schedules, habits in one place | Personalization + Simplicity | "Your personal focus control center" / "Votre centre de contrôle focus" |
| 2 | **App & website picker (blocking)** | Selecting apps/sites to restrict | Personalization | "Block exactly what distracts you" / "Bloquez exactement ce qui vous distrait" |
| 3 | **Focus Mode session active** | A timed session running, distractions blocked | Simplicity | "Start a session. Stay focused." / "Lancez une session. Restez concentré." |
| 4 | **Blackout / deep-work mode** | Stricter session screen | Personalization | "Go deeper with Blackout Mode" / "Allez plus loin avec le mode Blackout" |
| 5 | **Planned Pauses & Daily Limits** | Scheduling UI + a daily limit set | Personalization + Simplicity | "Schedule pauses and daily limits" / "Planifiez pauses et limites quotidiennes" |
| 6 | **Progress / insights** (optional) | History, streaks, screen-time reclaimed | Simplicity | "See your screen time come back" / "Reprenez votre temps d'écran" |

> Keep screen #1 and #2 strongest — they drive the install decision and visibly carry both pillars.

---

## 3. Production checklist

- [ ] Capture on a real iPhone (or device-accurate simulator) at exact pixel sizes above
- [ ] Real, clean data in the UI (no "Lorem ipsum", no debug overlays, no placeholder names)
- [ ] No competitor app names/logos visible in the blocking picker mockups (use generic categories or neutral examples)
- [ ] Captions match brand voice; no "AI", no "impossible to bypass" or lockout claims
- [ ] Status bar clean (full battery, no notifications, sensible time)
- [ ] EN-US set + FR set both produced
- [ ] 6.9" set (1320×2868) uploaded
- [ ] 6.5" set (1242×2688) uploaded
- [ ] Order set so screens 1–3 lead
- [ ] (Optional) App Preview video — same two iPhone sizes if produced; not required for first submission

⚠️ FOUNDER / design: if marketing frames + caption text are baked into the images, ensure text stays legible at thumbnail size and within Apple's safe areas.
